# GrasslandDynamics

Interactive Streamlit app for exploring grassland growth and cutting management using the **ModVege** model and Swiss weather data.

Explore leaf area index (LAI), biomass, daily growth, soil water availability, and the effects of cutting and temperature. Available weather stations: Bern, Davos, La Chaux-de-Fonds, and Lugano.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## References

- Jouven et al. (2006), *Grass and Forage Science*: ModVege model.
- MeteoSwiss Open Data: daily weather observations.
